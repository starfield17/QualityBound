# v3.6.2

- Preserve custom analysis profiles and saved encoder choices during settings,
  translation and asynchronous detection. Unsupported explicit choices stay
  visible until replaced; startup can recover from a broken default preset.
- Keep queue selection and details when sorting, synchronize sort indicators,
  and sort displayed bitrate and assigned encoders consistently. Busy queues
  reject editing, deletion and reordering; preserved size misses remain protected.
- Scan mixed file/folder drops in the background with each source root retained.
  Directory enumeration and capability queries can be cancelled during shutdown.
- Give setup an independent scroll area above the queue. Correct detached-window
  drag overlays, toolbar roles, progress selection backgrounds and HiDPI rendering.
- Make log following, Info/Debug levels and error filtering agree with their
  controls. Do not classify normal filenames or `failed=0` as errors.
- Show decision consequences directly, distinguish estimates from published
  output, and display size-limit proportions without overflowing on large files.
- Restore comparison geometry, retain native input/navigation keys, add separate
  A/B frame shortcuts, and allow comparison while a constraint decision is open.
- Add bitrate units and validation, repair focus navigation and path diagnostics,
  localize GUI-owned errors, and remove unused translation messages.

Verification uses the complete local async-exception-gated suite, all three
Pyright scopes, Ruff, architecture/workflow contracts, generated-icon checks and
compileall. An external FFmpeg 9.0.2 smoke used a generated three-second,
320×180, 24 fps MPEG-4/AAC clip to check precise seeking, independent frame steps,
play/pause and PCM output. This synthetic smoke does not measure encoding quality.
Physical-pixel rendering has a 2× regression check. Native Windows/Linux packaging
and the release artifacts are covered by Verify/full and the release workflow.
