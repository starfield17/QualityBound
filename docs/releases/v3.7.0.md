# v3.7.0

## Languages

- Keep English and Simplified Chinese text beside the code that displays it.
  Short text is declared inline; long and shared text belongs to its functional
  owner. Language switching still updates controls, queue status, menus and
  notifications without changing selected encoding options or running tasks.
- Replace translation keys, JSON catalogs and resource discovery with immutable
  bilingual text values. Both languages are checked for complete declarations
  and matching format placeholders. The existing displayed wording is preserved.
- Remove external JSON language packs and translation overrides. Existing files
  are left on disk but are no longer read. Supported language codes remain
  `en` and `zh_cn`; a saved unsupported language falls back to English.
- Packages no longer need language-resource files to start. Presets and other
  application resources remain bundled.

## Fixes included since v3.6.1

This release also includes the GUI changes prepared for v3.6.2, whose release
was blocked by a Windows test failure.

- Test both case-preserving and case-folding source-path deduplication policies
  on every OS, including repeated additions within and across intake batches.
  This fixes the Windows CI assumption without skipping the regression test.
- Preserve custom analysis profiles and saved encoder choices during settings,
  translation and asynchronous detection. Unsupported explicit choices stay
  visible until replaced; startup can recover from a broken default preset.
- Keep queue selection and details when sorting, synchronize sort indicators,
  and sort displayed bitrate and assigned encoders consistently. Busy queues
  reject editing, deletion and reordering; preserved size misses remain protected.
- Scan mixed file/folder drops in the background with each source root retained.
  Directory enumeration and capability queries can be cancelled during shutdown.
- Give setup an independent scroll area above the queue and return capped setup
  space to the queue. Correct detached-window drag overlays, toolbar roles,
  progress selection backgrounds and HiDPI rendering.
- Make log following, Info/Debug levels and error filtering agree with their
  controls. Normal filenames and `failed=0` are not classified as errors.
- Show decision consequences directly, distinguish estimates from published
  output, and display size-limit proportions without overflowing on large files.
- Restore comparison geometry, retain native input/navigation keys, add separate
  A/B frame shortcuts, and allow comparison while a constraint decision is open.
- Add bitrate units and validation, repair focus navigation and path diagnostics,
  localize GUI-owned errors, and remove unused translation messages.

## Verification

The local async-exception-gated suite passes 747 tests with one existing
platform-specific skip. Ruff, all three Pyright scopes, architecture/workflow
and installer contracts, generated icons and source compilation pass. A source
migration audit checks all 543 previously used message keys: the 510 distinct
English/Chinese text pairs are unchanged. Removing catalog parsing reduces the
ratcheted inference debt from 568 to 559 diagnostics.

Publication requires CI and Verify/full on the tagged commit, including native
Linux/Windows/macOS tests, the Windows installer contract and all five native
candidate builds. The release workflow then rebuilds the eight release packages
and publishes their SHA-256 checksums.
